Fig 6 · The framework

Bundle, Buy, or Build

Jio has three ways to move beyond telecom. Each has a different cost profile and a different way to fail.

Mode 1
Bundle
Put the product inside something the user already pays for
Core question

Can it ride the recharge or the router?

Cost profile

Low marginal cost. Mostly hardware subsidy or network capex.

Metric that matters

Attach rate, ARPU uplift, churn reduction

How it fails

Users take it as a free extra but never value it

Jio examples
JioPhoneJioBharatAirFiberJioFiberJioTV
Mode 2
Buy
Acquire or rent the preference that Jio can't create itself
Core question

Who already owns what users want?

Cost profile

Large, upfront, often recurring (rights renew; partners renegotiate)

Metric that matters

Paid conversion, cost per subscriber, renewal economics

How it fails

The seller captures the value; Jio overpays to rent

Jio examples
IPL rightsJioStar (Disney)SaavnGemini offer
Mode 3
Build
Create a standalone product that users choose on its merits
Core question

Would users pick it if it weren't from Jio?

Cost profile

Ongoing R&D plus customer acquisition; slow J-curve

Metric that matters

Unprompted retention: DAU/MAU, D30

How it fails

Installed but never opened, losing to a specialist

Jio examples
JioChatJioMeetJioPagesJioMart (app)

How I classify each case: follow the money

Most products mix modes. JioHotstar is bundled into plans, but the bulk of the spending was on buying rights and merging with Disney, so it counts as Buy. JioMart is built, but it runs on Reliance Retail's stores. A case's primary mode is where most of the money went.

Framework: the author's. Each case is classified by its dominant strategic investment mode (author's assessment), usually where most of the money went.
