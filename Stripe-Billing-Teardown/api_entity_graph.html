Customer

Stores payment methods, tax IDs, and billing history. Tied to the Product and Price catalog.

Subscription

The operational core state machine. Connects Customer to Prices, managing cycles, trials, and proration.

Invoice

Calculated financial statement at cycle end. Itemizes base fees, usage overages, taxes, and discounts.

PaymentIntent

Executes the actual transaction across global card rails, transitioning state upon success or failure.

Webhook

Fires real-time events back to the merchant's server to grant or revoke app access.
